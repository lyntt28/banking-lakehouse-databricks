# Gold BI: dashboards to rebuild on Databricks SQL

Source: three dashboards previously built with Flask + PostgreSQL + Chart.js/ApexCharts
(CARD, LOAN, DEPOSIT). Gold must provide one table/view per visual so each chart is a
plain `SELECT` with filters.

Common filters: report date, region, branch, product, customer type (consumer/corporate).
Common comparisons: vs last day (D-1), last month-end (M-1), last year-end/same day (Y-1),
% of month target, % of year target.

## 1. Card Business Dashboard (CARD)

Marts `card_mart_kpi_daily`, `card_mart_kpi_monthly`, `card_mart_spend_mix` via `gold_serving` +
`gold_serving.card_report_calendar`. Definitions, targets, migration:
[card_dashboard.md](card_dashboard.md).

## 2. Overdue Dashboard (credit card overdue tracking)

Source `gold.card_mart_overdue_daily` (file `credit_card_overdue_YYYYMMDD.txt`) read through
`gold_serving` + `gold_serving.overdue_report_calendar`. Rules, date logic, datasets and runbook:
[overdue_dashboard.md](overdue_dashboard.md).

| Visual | Metric |
|---|---|
| 3 tickers + vs D-1 / M-1 / Y-1 (actual dates) | Overdue ratio, overdue balance, ending balance (USD) |
| Bar + line, last 5 published days and 6 months | Overdue amount (K USD), overdue ratio % |
| Stacked bar month x debt group | Overdue amount by `del_grp` |
| Pie + bar by product group | Overdue amount / Top-5 ratio |
| Top-5 branches (treemap rules) | Ratio + amount, excl. 8125, > 10,000 USD |

## 3. Retail Deposit Performance Dashboard (DEPOSIT)

Marts `dep_mart_trend`, `dep_mart_monthly`, `dep_mart_by_tenor`, `dep_mart_casa_customer`,
`dep_mart_new_accounts` read through `gold_serving` + `gold_serving.deposit_report_calendar`.
Metric definitions, filters, migration: [deposit_dashboard.md](deposit_dashboard.md).

## AI/BI dashboards vs the original (what matches, what cannot)

Built from the original source (the old Flask + Chart.js dashboards, since removed from the repo): same sections and order, same
titles, same chart type per visual, same colour per series, same relative widths
(Lakeview grid = 6 columns: `1fr 1fr` → 3+3, `1fr 1.5fr` → 2+4, `1fr 2fr` → 2+4).
Filters: report date (latest data on or before the date), customer type (Card),
branch (Overdue), region (Deposit).

| Original | AI/BI dashboard | Why |
|---|---|---|
| KPI card shows value + MoM/YoY + % target in one box | counter + comparison table under the row | counter shows one value |
| New Acquisition: stacked bars + dashed "Total" line | stacked bars (stack top = total) | no line overlay on stacked bar |
| Sales Volume bar gradient `#3B82F6 → #DBEAFE` | solid `#3B82F6` | no gradients |
| Deposit gauges (half-circle) | counters in % with the gauge colours | no gauge widget |
| MoM chart: 2 stacks per month (this year / last year) | grouped bars, same 6 colours | one stack per category |
| Section headers with yellow gradient | Markdown headers | text widgets have no background |
| Five KPI cards in one row | five 1-column counters (6th column empty) | 6-column grid |
